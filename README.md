# Site Tematico

Site tematico de produtos, desenvolvido com HTML e CSS puro, com um carrossel de produtos em destaque.

## Funcionalidades

- Carrossel de produtos com navegacao entre itens
- Layout tematico com fontes personalizadas

## Tecnologias utilizadas

- HTML5
- CSS3

## Como executar

1. Clone este repositorio
2. Abra o arquivo index.html no navegador
